# Goal

## Project
pycm — Python Confusion Matrix Library

## Description
PyCM is a multi-class confusion matrix library written in Python that supports both input data vectors and direct matrix input. It is a comprehensive tool for post-classification model evaluation supporting most classes and overall statistics parameters. PyCM provides extensive metrics for predictive models including class-based statistics (TPR, TNR, PPV, NPV, F1, etc.), overall statistics (Kappa, accuracy, AUC, etc.), and various benchmarks for interpreting results.

Key features:
- Create confusion matrices from actual/predicted vectors or from matrix input
- Calculate 60+ class-based metrics and 40+ overall metrics
- Provide interpretation benchmarks for metrics (Landis & Koch, Fleiss, Altman, etc.)
- Support weighted metrics and confidence intervals
- Compare multiple confusion matrices
- ROC curves, PR curves, and other curve types
- Multilabel confusion matrix support
- Export to CSV, HTML, and other formats
